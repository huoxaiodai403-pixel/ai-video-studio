# 朋友版：从创作到成片

朋友版提供代码动画与手绘白板两条制作路线。先让 Codex 创作并提交短样片，在工作台检查结果、选择声音、保存工程；也可在代码动画页使用自己已配置的编剧服务。无需先安装本地大模型。

## 先做一个短样片

1. 在 Codex 打开工作台目录，使用 `$ai-video-studio`，说明主题、受众、画风、时长和声音偏好。让它先检查当前工具与工作台状态。
2. 让 Codex 写口播、安排分镜。代码动画保留自包含 HTML、Canvas 或 SVG 源码；白板保留逐镜旁白与视觉要点。
3. 生成短样片，实际检查文字、构图、运动、配音和结尾。计划时长只是估计，有声版本以实际合成的音轨为准。
4. 反馈具体镜头和问题，让 Codex 修改。也可在对应网页编辑工程，然后重新生成。
5. 满意后渲染完整片段，到“我的作品”预览、下载或送到剪映精修。长内容先拆成可审看的片段。

Codex 会话的媒体工具与用量由朋友自己的账号决定。网页不会调用当前聊天的内置生图或桌面工具；安装 Skill 也不会额外授予这些能力。

## 代码动画

从“工作流”打开“代码动画”。Codex 可以保存创作计划，再提交动画源码进行预览或完整渲染。页面的高级入口也可手动导入已有 HTML；正常创作不要求自己编写请求数据。

如果希望直接在网页创作，先在设置中配置实际可用的编剧服务，然后填写需求、点击“生成创作方案”，审看分镜后生成样片。编剧服务与 Codex 当前会话是两个独立入口。未配置编剧时，仍可由 Codex 写好动画交给本机渲染器。

代码动画适合文字、图形、关系与步骤演示。它不能直接替代人物视频模型，也不会因为使用代码就自动获得好的设计。自包含画面应使用本机可用字体与素材，先检查缺字、溢出、节奏和结尾。

有声版本需要可用的配音引擎。代码动画输出的 SRT 按真实音轨的镜头时长分段，尚未逐词对齐，也不表示字幕已烧录到画面。渲染器有尺寸、帧数与时长预算；超过预算的内容需要拆分。

## 手绘白板

从“工作流”打开“手绘白板”。先准备少量镜头，每镜只说明一个要点，让文字与图形按解说顺序出现。检查画面预览后，再制作有声视频。

白板的 CPU 渲染不要求安装图像模型。使用包内公开贴纸、图形或自己准备的真实素材；需要新插图时，可由当前具备生图工具的 Codex 制作后交给工作台。不要把缺少的图片当作已生成素材。

## 保存与审看

- 工程、样片和成片统一在“我的作品”管理。生成完成表示已有文件，仍需看片与试听。
- 代码动画计划支持逐镜音色和审阅记录。“通过”需要实际关联的媒体、具体审阅记录和你的明确选择；不会自动替你验收。
- 修改已有素材对应的内容或全片声音后，需要重新检查受影响镜头。旧素材和记录保留，不能把旧片当作新修改已经完成。
- 同一计划在两个窗口修改时，过期保存会提示冲突。先保留当前编辑，再重新载入并合并。
- 自动生成失败后，可按原任务快照继续未完成部分；想采用新编辑的计划时，应新提交任务。手动源码渲染不依赖编剧服务。

剪映精修从已完成作品的详情开始。草稿生成、剪映打开、MP4 导出与成片审看分别确认，具体模式见 [剪映说明](jianying-windows.md)。朋友版与完整版的范围见 [版本定位](editions.md)。
