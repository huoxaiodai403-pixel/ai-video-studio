# 在工作台里创作视频

从「工作流」进入「生成工坊」，选路线、填写内容、选择音色，然后在网页里生成和修改方案。
你可以直接使用工作台完成创作；「交给 Codex」是给高级用户或朋友复用计划的可选入口。

## 从视频 Skill 开始

「工作流」目录列出 10 种文章创作方法和 8 个通用制作工具，可按题材筛选或搜索。选择方法后，生成工坊会展示准备条件与实际能力边界；点击「用我的内容创作」填写自己的主题与文稿；「用示例新建计划」仅提供可编辑参考。已有计划会先保存，保存失败则不替换。白板方法进入原生白板编辑器。

方法复用代码动画、角色叙事、白板等现有生产能力。精细拼贴、复杂角色与上游专用模型仍按方法说明准备素材；方法数量不等于独立渲染引擎数量。「查看已有作品」直接筛出对应的本地样片，便于先看片，再修改自己的内容。

## 先做一个短样片

1. 填写选题、受众、希望说明的问题，以及画风、角色和参考材料。选择全片音色；需要多角色时再给镜头设置独立音色。
2. 点击「生成创作方案」，检查每镜旁白、画面、主要动作和运镜。也可以直接手写分镜。自动编剧使用设置里配置的服务。
3. 先生成样片，实际播放并检查角色、文字、动作、配音与字幕。计划中的秒数是估计，口播生成后才有真实音频时长。
4. 在镜头审阅记录中写清问题。需要修改的镜头标为「待返修」；查看真实产物后，再显式选择「通过」。
5. 满意后制作完整内容，到「我的作品」查看任务与文件。长内容先按章节验证，不用重复画面补足目标时长。

同一个计划在两个窗口中修改时，过期保存会提示冲突。保留当前编辑内容，重新载入并合并，不要直接覆盖另一窗口的修改。

修改已有产物镜头的旁白、画面、动作、运镜、参考、音色或计划时长后，该镜头会变为「待返修」。
修改全片风格、角色或音色会使已有产物的镜头都需要复查。旧素材路径与审阅记录会保留，重新审看后才能再次选择「通过」。
生成失败时，可以使用「继续失败任务」按原任务的计划与音色配置快照续跑；若要采用新编辑的内容，应另行提交生成任务。

## 六条路线如何选

| 路线 | 适合内容 | 开始前需要什么 |
| --- | --- | --- |
| 代码动画 | 概念解释、关系图、产品演示、文字与图形动作 | 编剧服务和本机浏览器渲染组件；先检查短样片 |
| 角色与风格短片 | 火柴人、故事角色、带风格的有声叙事 | 一致角色参考及可用图像、语音模型；开启模型动态还需可用 Wan 视频模型 |
| 角色循环动画 | 表情、动作循环和透明动画素材 | 自动生成使用 FLUX 参考图引擎；高级组帧可使用至少四张已有不同姿势 |
| Blender 镜头预演 | 人物走位、相机路线、空间与遮挡 | 本机 Blender；先以几何白模验证镜头 |
| 手绘白板 | 方法、步骤、知识讲解 | 旁白与少量视觉要点；继续使用白板编辑器 |
| 知识与调查长片 | 资料解释、来源核对、章节叙事 | 来源原文、素材覆盖和可审阅口播；继续使用长片编辑器 |

## 正确理解状态与能力

- **生成完成**说明已有文件，仍需审看片和试听；它不会自动把镜头改为「通过」。
- **通过**是你的明确选择，需要关联现有媒体并填写审阅记录。文件存在、能够解码或模型已安装都不能代替画面和听感判断。
- **代码动画**用程序控制画面；它不会自然拥有写实人物视频模型的能力。复杂角色、特效和视觉风格都需要真实样片检查。
- **代码动画字幕**目前另存为 SRT，按真实音轨的镜头时长分段，尚未逐词对齐；不要把这个文件当成已经烧录到画面的字幕。
- **角色叙事样片**生成首镜真实有声视频，包含配音与字幕。默认以插画推近呈现；在本页勾选模型动态后，直接调用所选 Wan 工作流生成动态镜头。运行成功仍需检查角色身份、肢体动作、口播与字幕。
- **角色循环自动生成**使用 FLUX 参考图引擎，先确定角色母版，再生成四个关键姿势并制作透明 GIF/WebP。高级组帧入口处理你选择的已有图片，不会自动补画缺少的姿势。
- 自动动作拆解支持点头、挥手、左右摇头与眨眼；其他动作可在四个镜头中分别填写关键姿势。系统会拦截几乎相同的姿势图，但通过这项检查仍不表示动作自然。
- **循环动画组帧**不会凭空推断两张姿势之间的肢体动作。GIF 透明是二值的，WebP 可以保留透明渐变；内部绿色、发丝边缘、循环接缝应单独检查。
- **Blender 白模**表达空间、相机和走位，不能当成已经完成的生成式真人视频。将白模交给 Seedance 等云服务是后续独立步骤，需要配置服务且确认支持参考视频等输入。
- 样片成功只说明这次输入跑通。换角色、语言、题材或模型后，需要重新检查；路线列表不承诺所有外部 Skill 或云模型已经可用。

完整的原文链接及其路线对应关系保存在
[生成路线目录](../workflows/generation-routes.json)。工作台采用简短方法总结，参考文章中的播放量、收入、作者耗时或自评分数不作为出片质量承诺。

## 自定义出片与制作交接

默认按本次输入重新设计画面和制作配音。图像叙事可使用 ComfyUI，代码动画会生成新的画面代码；Simon 在原生白板编辑器输入新主题与旁白。先审阅分镜，再生成样片和完整视频。

固定示例复刻须明确勾选，不根据新文字重画场景，并使用 Windows 声音。正式制作保留所选声线，不将系统声音作为已有高级音色的替代。

角色库、小说与长片复用、Codex 接管、Blender 和镜头交回合成见 [自定义视频、角色与制作交接](production-paths.md)。提交冻结本次输入；制作中的新编辑不改变已提交任务，产出仍需逐镜视听。
