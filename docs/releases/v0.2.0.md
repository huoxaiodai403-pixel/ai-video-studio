# v0.2.0 · Codex 与 Windows 剪映联通

作品现在可以从工作台交接到剪映精修，再将导出成片放回原作品统一预览和下载。

- “我的作品”新增“送到剪映精修”，支持自动选择、素材分轨和成片交接。
- 可用的镜头、角色配音、背景音乐和字幕分别生成轨道；缺少独立画面的白板/讲解镜头重建为可编辑文字卡片。原手绘动效不自动迁移，成片交接可保留原视频外观。
- 自动读取剪映实际草稿目录；素材复制进独立新草稿，同内容重复交接不覆盖已在剪映修改的工程。
- 剪映导出的 MP4 保存到交付目录后，回到原作品点“刷新状态”即可预览和下载；写入中的文件不会显示为可下载成片。
- Codex Skill 新增 `jianying status`、`jianying export`、`jianying open`。

## 下载与安装

- `ai-video-studio-0.2.0-windows.zip`：工作台、安装与启动脚本、Skill、公共示例和文档。
- `ai-video-studio-skill-0.2.0.zip`：单独分享的 Skill，需要已安装并运行的工作台。
- `SHA256SUMS.txt`：两个 ZIP 的校验值。

新用户解压工作台包后运行 `Install.cmd`，然后运行 `Start.cmd`。首次安装需要网络与兼容 Python；缺少 Python 时安装器会通过 winget 安装 Python 3.12，没有 winget 时请先安装 64 位 Python 3.11–3.14。

运行 `scripts/Install-CodexSkill.ps1` 安装 Skill。剪映功能另需从官网下载剪映并完成首次启动，再运行 `scripts/Install-JianyingBridge.ps1` 安装隔离的草稿依赖。安装、模式及导出步骤见 `docs/jianying-windows.md`。

剪映组件单独要求 64 位 Python 3.12–3.14。基础工作台若使用 Python 3.11，请按剪映说明另装 3.12 并用 `-PythonPath` 指定；安装脚本会预检所用解释器及已有桥接环境。

从 v0.1.0 升级时先备份本机目录，再用新包覆盖源码、更新 Skill 并重启工作台；保留自己的 `config`、`projects`、`models` 和运行环境。

## 验证与范围

已在剪映专业版 11.5.0.14471 实际打开一个双角色、三镜头、10 轨草稿，并由桌面操作导出约 35 秒的 1080p/30fps H.264/AAC 成片。1047 帧完整解码通过，抽帧及工作台实际播放通过；未完成主观音色听辨。工作台 219 项测试完成（2 项按环境跳过），隔离草稿组件 14 项、Skill CLI 15 项测试通过。

草稿接口负责生成草稿与启动应用，不等于无人值守一键导出。剪映内编辑和导出仍由用户或具备 Windows 桌面工具的 Codex 完成；其他剪映版本、特效和模板需要另行验证。

分享包不包含剪映安装程序、模型权重、私人作品、音色录音、参考照片、配置或 API 密钥。实际生成仍需配置相应媒体引擎。
