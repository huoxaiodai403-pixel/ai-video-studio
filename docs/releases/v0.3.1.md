# v0.3.1 · 统一工作台与部署修复

自己和朋友使用同一个工作台。网页、Codex、ComfyUI 和 Blender 制作入口保留，本地模型按需另装；默认安装与启动不下载或启动模型。

## 下载与安装

- [Windows 工作台](https://github.com/huoxaiodai403-pixel/ai-video-studio/releases/download/v0.3.1/ai-video-studio-0.3.1-windows.zip)：下载后解压，先运行 `Install.cmd`，成功后运行 `Start.cmd`。
- [可选 Codex Skill](https://github.com/huoxaiodai403-pixel/ai-video-studio/releases/download/v0.3.1/ai-video-studio-skill-0.3.1.zip)：连接工作台的对话入口，工作台包内也已附带。
- [SHA256 校验文件](https://github.com/huoxaiodai403-pixel/ai-video-studio/releases/download/v0.3.1/SHA256SUMS.txt) 与 [文件清单](https://github.com/huoxaiodai403-pixel/ai-video-studio/releases/download/v0.3.1/release-manifest.json)。

需要 Windows 10/11 x64、可写目录和首次安装网络。不要求 Git、winget 或管理员权限；缺少兼容 Python 时安装经过固定 SHA-256 校验的应用内 Python。默认同时安装 FFmpeg、Node、CPU 渲染依赖与 Chromium。此包不是完整离线环境，不含模型权重或个人配置、工程、素材、音色录音及机器日志。

安装、端口选择、更新和工程迁移步骤见[部署说明](https://github.com/huoxaiodai403-pixel/ai-video-studio/blob/v0.3.1/docs/deployment.md)。旧版升级前先备份 config、projects 及引用的素材；推荐新目录安装后迁移自己的数据，不复制虚拟环境。未保存的旧浏览器草稿保留，可从页面底部下载备份。

## 本次修复

- 安装器支持独立 Python；下载校验和有限重试，损坏环境先完整备份再重建，保留用户工程。
- 启动器核对实际服务目录，同目录复用，端口冲突明确报错；不会误连或终止其他工作台。
- 渲染诊断真实加载依赖与检查浏览器，避免依赖文件被移除后仍显示可用。
- 全部草稿编辑器接入共享的安装目录隔离机制，修复同一端口复用导致串入其他目录草稿；使用现有设计系统。
- 安装文档同步说明 CPU、在线服务、Codex 和可选模型各自依赖，明确安全软件拦截处理及跨电脑迁移方法。

统一工作台同时包含此前尚未公开发布的共享 UI、十种视频文章方法入口、自定义计划、角色与声线管理、审片返修，以及 Codex / ComfyUI / Blender 制作交接。入口可用不等于每个可选引擎已在目标电脑安装或完成质量验收。
