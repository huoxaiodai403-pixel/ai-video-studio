# v0.3.0 · 朋友版与完整研发版

本版把分享范围明确为两条线：公开的朋友版围绕 **Codex 创作、代码动画、手绘白板、配音、作品库和剪映交接**；完整模型与工作流开发放入私有 `ai-video-studio-dev`。定位见 [版本说明](../editions.md)。

## 朋友版的主要变化

- Codex 可直接写口播、分镜和可渲染动画，再通过 Skill 把真实文件或计划交给工作台。代码动画与白板的 CPU 渲染，不要求预装本地大模型。
- 新增代码动画制作入口：保留画面源码，先生成样片，再检查文字、构图、运动、配音和结尾。已有 HTML 也可导入渲染。
- 创作计划支持风格、角色、镜头动作、运镜和独立声线；保存版本与本机未保存草稿分开处理，避免过期保存覆盖另一处修改。
- 计划、预览和视频统一在“我的作品”管理，增加“生成工坊”类型筛选。渲染后的素材可以关联回计划；编剧执行记录不会把同一份已完成计划重复显示为新作品。
- 保留“已生成”“需要返修”和明确人工验收的区别。修改已经有素材的内容后，需要重新检查相关镜头。
- 保留轻量配音和剪映交接：Windows 系统语音可离线运行，Edge 需联网；剪映使用独立草稿桥接环境，按工程实际素材选择交接方式。
- 公共页面统一导航与内容布局；首页突出开始创作和继续工程，作品与资源分开管理，音色库优先显示用户自己的预设。

朋友版以 Codex 创作为主要入口，代码动画也可使用自己已配置的网页编剧。更多模型自动流程与实验路线在完整版维护；不能把 Codex 订阅当作工作台所有媒体接口的通用凭据。

## 下载与更新

在[公开仓库 Releases](https://github.com/huoxaiodai403-pixel/ai-video-studio/releases)下载朋友版：

- `ai-video-studio-friend-0.3.0-windows.zip`：Windows 工作台。
- `ai-video-studio-friend-skill-0.3.0.zip`：单独的 Codex Skill。
- `SHA256SUMS.txt`：同一 Release 的下载校验值。

完整版的 `ai-video-studio-development-0.3.0-windows.zip` 在私有研发仓库维护，不作为公开朋友版附件。

新用户解压工作台包后，运行 `Install.cmd` 安装依赖，再运行 `Start.cmd` 打开页面。希望配合 Codex 时，在工作台目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-CodexSkill.ps1
```

随后在 Codex 中打开工作台目录，开始新对话并使用 `$ai-video-studio`。Skill 包需要配套工作台；它本身不包含渲染器、模型或桌面控制能力。

旧用户先备份自己的配置与工程。朋友版不会打包原作者的作品、声音参考、密钥、模型权重或私人笔记，也不应拿发行包覆盖这些本机数据。

## 已验证的范围与仍需审看的部分

代码动画已用短片验证从计划、渲染到作品库、下载和浏览器播放的路径，并检查素材关联与待审状态。相关回归覆盖计划版本、预览分类、循环素材登记与失败任务可发现性。这些检查证明相应路径能运行，不代表所有题材、声音或机器已经通过成片验收。

- **自动编剧质量**：完整版的本机约 9B 编剧仍可能产生生硬表达、简单画面或不合适的运动设计。Codex 创作与本机编剧是独立入口，不把一条入口的效果归给另一条。
- **动作与一致性**：模型生成的角色身份、肢体动作、循环接缝和运镜仍需逐镜检查。角色模型、三维预演和长片试验不属于朋友版承诺的起步范围。
- **配音与字幕**：声音自然度取决于所选引擎和声线。Windows 字幕使用同次合成事件的词起点，不能称为声学强制对齐。代码动画输出的 SRT 按真实音轨的镜头时长分段，尚未逐词对齐，也不等于字幕已烧录进画面。
- **长片与渲染预算**：代码动画按短片段制作，有尺寸、帧数和时长限制；长内容需要拆镜和组织素材，不保证单次生成十分钟完整作品。
- **剪映**：社区草稿桥接不等于官方时间线 API，也不保证各版本、特效和模板无损兼容。打开草稿不等于导出成功；Codex 是否能继续操作剪映取决于当前会话的 Windows 桌面工具。
- **朋友的电脑**：包是可安装源码发行包。首次安装需要网络准备依赖，模型权重不随包附带；当前机器的小样通过不能替代另一台机器上的实际运行检查。

第三方模型、字体、依赖和素材仍适用各自许可证。更详细的操作和边界见 [快速上手](../getting-started.md)、[剪映说明](../jianying-windows.md)及包内 Skill。
