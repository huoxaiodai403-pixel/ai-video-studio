# v0.2.2 · 在线服务、本地模型与轻量配音

- 在线服务按图像、语音、转写、视频、编剧分别配置，支持保存状态、实际任务验证、错误指引、媒体预览与下载；验证仅在用户点击后发起。切换能力保留本页未保存内容。
- 本地模型在独立页面展示，列出文件、环境和 CPU / GPU 需求；文件存在不等于已验证生成效果，不自动下载权重。
- Windows 系统语音可用 CPU 离线生成配音与字幕，无需模型权重或 API Key。词起点来自同次合成事件，词尾取下一词起点，不声称声学强制对齐。
- Edge 在线语音免密钥，音频与词级时间一起返回；需要联网，可用性以本次生成结果为准。
- 火山引擎接回原 Simon 流程中的语音能力：支持 API Key 或 App ID + Access Token，校验资源 ID 与音色，读取音频后的字幕事件。凭证使用 Windows DPAPI 加密。
- 白板的有声渲染接入 Windows / Edge / 火山及 OpenAI 兼容 TTS。兼容 TTS 自动字幕需要额外的逐词 ASR；本地克隆音色继续使用本地语音流水线。
- 网页编剧支持工作台独立的官方 ChatGPT 账号授权：PKCE、身份签名校验、加密存储、刷新与断开连接、读取账号实际可用模型。账号资格和套餐额度由授权服务决定；不读取 Codex 或其他插件凭证。
- ChatGPT 此授权的支持范围为文本 Responses，不等于图像、视频、转写或配音授权。用户须亲自完成官方登录与授权后验证账号请求。
- 延续 v0.2.1 的 Simon 源码 / 字体 / 贴纸随包分发，以及缺少剪映时先询问再安装并配置桥接的流程。

## 使用

从 `/settings` 管理在线服务，从 `/models` 管理本地组件；从 `/speech` 试听，或在 `/whiteboard` 选择配音来源生成有声白板。配置和凭证不包含在分享包中。

账号与付费服务在未提供真实授权前只验证协议、参数与错误处理，不能据此宣称真实账号端到端通过。Windows / Edge 与白板成片另行通过本机实测核对。

## 本次验证记录

- 64 项账号授权、轻量语音、白板、分享包和音色库测试通过；Skill 客户端 17 项通过。账号覆盖 PKCE、签名 / nonce / audience、取消后迟到回调、刷新令牌轮换、撤销失败本机清除和流式完成确认。
- 浏览器验证五类能力切换时草稿保留、在线 / 本地独立入口、账号模型选择；1440 px 和 390 px 布局无横向溢出、无页面脚本错误。账号模型列表用固定测试响应验证交互，没有冒充真实账号授权。
- 页面真实调用 Edge 得到 WAV 与 SRT；Windows 离线合成一条 1920×1080、30 fps、9.6 秒白板 MP4（H.264 + AAC）。检查视频帧、音轨存在、字幕与词时间；声音自然度仍待用户试听。
- 全量 246 项测试仍有 3 个失败、9 个错误、3 个跳过，与 v0.2.1 的既有失败组一致（模型 / 参考音频 / 独立 ffmpeg / 调查源码等环境及原有用例）。不将相关测试通过写成全量通过。
