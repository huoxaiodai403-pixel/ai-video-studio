# 换电脑安装与迁移

同一份工作台用于自己和朋友的电脑。本地模型是可选模块；不要复制开发电脑的虚拟环境来代替安装。

## 安装

使用 Windows 10/11 x64，将完整源码或新构建的 Windows ZIP 解压到本机可写目录，例如 `C:\AI Video Studio`。支持中文和空格路径，推荐短路径；不要在 ZIP 内直接运行，也不要放到系统目录或网络共享。

双击 `Install.cmd`。默认安装独立网页环境、FFmpeg、Node、Simon / 调查片渲染依赖与 Chromium。没有兼容 Python 时，从 Python 官方 NuGet 包安装固定版本到工作台 `tools` 中，校验 SHA-256，不需要 winget、管理员权限或修改系统 PATH。下载失败会停止，不把不完整安装报告为成功；修正网络问题后可重试。

也可显式选择独立 Python，避免依赖电脑已有开发环境：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Studio.ps1 -IsolatedPython
```

已有 Python 时可传 `-PythonPath C:\Python313\python.exe`；只安装网页时加 `-SkipRenderers`，之后运行 `scripts/Install-Renderers.ps1` 补齐。安装器只改工作台目录，保留已有配置、工程和素材。不可用的旧虚拟环境会先改名备份，再重建；运行正常的环境继续使用。

首次安装需要访问 PyPI / Python 包文件、NuGet、nodejs.org、npm 和 Playwright 的浏览器下载站点。代理使用当前电脑配置，不携带开发电脑代理；企业网络禁止下载时需要由该电脑的管理员提供允许的网络或依赖分发方式。不要把源码 ZIP 当作完整离线运行包。

## 工作电脑首次部署（不安装本地模型）

1. 在目标电脑从 [v0.3.1 发布页](https://github.com/huoxaiodai403-pixel/ai-video-studio/releases/tag/v0.3.1)下载 `ai-video-studio-0.3.1-windows.zip` 和 `SHA256SUMS.txt`，核对哈希后完整解压到可写目录。
2. 保持安全软件开启，运行 `Install.cmd`。不需要先安装 Python、Git、Node 或本地模型；等待安装完成，首次下载依赖需要网络。
3. 运行 `Start.cmd`，在网页选择“手绘白板”，编辑自己的短分镜，先生成画面预览。使用 Codex 时，可让 Codex 在同一工作台编写和提交分镜。
4. 配音可选“Edge · 免密钥联网”及晓晓等音色；该模式会把旁白文字发送给微软语音服务。需要离线时选实际安装的 Windows 系统音色；未安装中文语音包的电脑不保证有中文系统音色。
5. 制作一段短片，在“我的作品”播放到结束，下载 MP4 和字幕，核对自己的内容。工程保存在当前安装目录；完成并保存后可正常重启目标电脑，再运行 `Start.cmd` 检查工程能否继续打开。

若安装或出片失败，保留失败时间、页面错误和当前目录 `logs` 中对应日志，先核对网络与所选引擎。不要通过复制另一台电脑的虚拟环境、API 配置或关闭防护来继续。安全软件拦截的处理见下文。

## 启动和诊断

双击 `Start.cmd`。启动器先确认当前目录的服务实际响应，再打开网页。同一目录重复启动会复用服务；端口被其他应用或其他目录的工作台占用时会明确报错，保留对方进程。

需要并存时，在工作台目录执行：

```powershell
.\Start.cmd -Port 8190
& .\tools\.venv\Scripts\python.exe .\skills\ai-video-studio\scripts\studio_client.py --url http://127.0.0.1:8190 doctor
```

默认端口为 8189。Skill 使用其他端口时传 `--url`，或为当前会话设置 `AI_VIDEO_STUDIO_URL`。启动失败查看 `logs/studio.err.log`；网页能打开后，doctor 的 `root` 必须指向这次安装目录。不要因为端口可连接就判断启动成功。

## 可用功能与需要另装的组件

| 使用方式 | 新电脑还需要什么 |
| --- | --- |
| 编辑分镜、角色库、素材管理、帮助 | 基础安装即可；初次没有个人工程或音色 |
| Simon 白板、HTML / Canvas 动画与素材合成 | 默认 CPU 渲染组件；有声视频需所选语言的 Windows 语音包、在线声音或导入音频 |
| 10 个文章方法的自定义创作 | 内置方法与计划入口已随包提供；网页自动编剧 / 生图需自行配置相应后端，Codex 可提供分镜、动画和素材 |
| 原始文章 Skill 资料 / 固定示例复刻 | 按制作说明安装固定版本资料；部分示例需要另行制作或导入素材，不携带作者的个人成片与素材包 |
| HyperFrames / 通用 Remotion 组合制作 | 运行 `scripts/Install-VideoTools.ps1`，这些可选组件不等同于默认调查片渲染器 |
| Blender 完整动画或几何预演 | 安装官方 Blender；也可用 `AI_VIDEO_BLENDER` 指定本机 `blender.exe` |
| ComfyUI、Qwen、Wan、其他本地模型 | 分别安装引擎、独立环境与权重，确认硬件满足要求；不由普通启动自动开启 |
| 在线服务与 Codex | 使用新电脑自己的账号 / API 配置；不转发原电脑凭据 |

不应把开发电脑上已有 GPU 服务、浏览器缓存、Python 或 npm 全局安装作为验收前提。没有本地模型不影响基础安装；自动生成仍需要所选生成器，不能把入口可点等同于已具备该引擎。

## 自己的工程迁移与更新

1. 先在新目录完成源码安装，确认工作台可启动。
2. 停止旧工作台的制作任务并备份数据。自己的工程与素材可单独迁移；给朋友分享源码包时不附带个人数据。
3. `projects`、`assets` 和角色 / 音色配置中的素材引用需要一起核对。绝对路径、外部素材、模型路径、剪映草稿和参考录音不会因为复制源码自动迁移；缺失时重新导入或在设置中选择新路径。
4. 在线服务凭据在新电脑重新填写。不要复制 `tools/.venv` 或模型 worker 的 `.venv`；在目标目录重新安装。更新源码也不能覆盖已有 `config`、`projects` 与素材。
5. 重新打开一个已有工程，确认角色、音色、镜头素材与字幕，制作短样片后再继续长片。

浏览器草稿按安装目录隔离。同一端口切换工作台不会自动带入另一目录的未保存内容；同一目录刷新或重启仍保留草稿。升级前的旧草稿原文不会删除，页面底部“旧浏览器草稿备份”可下载到本地核对。已经保存的工程以当前目录的“我的作品”为准。迁移时先保存工程，不要只依赖浏览器临时草稿。

Python 官方明确指出虚拟环境应在目标位置重建：[venv 文档](https://docs.python.org/3.12/library/venv.html)。应用目录内的 Python 使用官方提供的 [NuGet 包](https://docs.python.org/3.13/using/windows.html#the-nuget-org-packages)。

## 安全软件拦截

如果安装脚本被隔离、进程退出或出现卡巴斯基 `PDM:Trojan.Win32.Generic`，立即停止该安装链路，保留检测时间、脚本路径、SHA-256 与安装日志。不要循环恢复并执行，不以关闭保护或整目录排除作为安装条件。先核对源码提交、下载哈希及厂商分析结果；重新验收必须保持防护开启。
