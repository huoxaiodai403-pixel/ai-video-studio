# 朋友版运行依赖

朋友版从 CPU 渲染与基础配音开始，不默认安装本地编剧、图像或视频大模型。使用 Codex 写稿和编写动画，不要求在工作台部署一个本地编剧模型。

## 基础安装

双击根目录的 `Install.cmd`，准备 Python、轻量网页环境、Node、浏览器渲染组件与 FFmpeg。首次安装需要网络。完成后双击 `Start.cmd` 打开页面，再做一次短预览；安装日志成功不等于声音和视频已经通过检查。

如果安装时跳过了渲染器，可在工作台根目录补装：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Renderers.ps1
```

代码动画使用本机浏览器渲染器；手绘白板还使用随包固定版本的 Simon 源码、字体与公开贴纸。包内包含这些公共源码和许可证，运行依赖在本机准备，不含 AI 模型权重。

## 先选一种能运行的配音

| 方式 | 需要什么 | 先检查什么 |
| --- | --- | --- |
| Windows 系统语音 | 本机已安装的系统声音 | 短句试听、语速、缺字与字幕 |
| Edge | 可用网络 | 短句是否能成功合成，以及实际听感 |
| 自己配置的在线语音 | 提供方支持的接口、模型、凭据与额度 | 具体配音能力及返回格式 |

在配音页先试听一句，再到音色库保存适合自己的预设。分享包不附带作者的录音、克隆声音、模型或接口凭据。无需为了试听 Windows 声音安装 GPU 推理环境。

已经自行安装并接好工作台支持的本地配音引擎时，也可使用对应声音；必须在当前电脑实际检查组件并合成试听。朋友版不提供高级模型安装和管理入口，不会仅凭选择了一个引擎就自动下载或部署它。

## 可选编剧与剪映

网页的自动方案和代码动画编写需要实际可用的编剧服务，在设置中配置自己的服务。Codex 当前会话与网页编剧是两个入口，不能把订阅视为所有接口的通用凭据。只有手动渲染已有动画源码时，不需要编剧服务。

剪映精修使用独立草稿桥接环境，要求 64 位 Python 3.12–3.14 和已安装的剪映客户端。准备方法见 [剪映说明](jianying-windows.md)。首次在朋友电脑上使用时，需要检查实际草稿和导出结果。

遇到问题先看具体任务错误：缺渲染器就补渲染组件，配音失败先回到短句试听。不要复制他人的 `ready` 检查记录，也不要把未安装组件手工标为“已就绪”。更多模型与实验路线由完整版维护，见 [版本定位](editions.md)。
