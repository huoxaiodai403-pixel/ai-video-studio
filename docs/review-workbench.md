# 审片与返修

从作品库打开实际视频，点击“审片与返修”。样片和成片均可审看，功能不依赖本地模型。

1. 完整播放并听声音，再用 0.5× 慢放和约一帧按钮查看细节。
2. 点击“标记此刻”，填写具体问题和希望的改法。时间取自播放器，时长和帧率取自实际文件，不使用计划时长。
3. 检查内容与画面、文字与字幕、动作与连续性、声音与同步、片尾与交付。可以选择“不适用”。
4. 保存记录，或复制包含五项检查和时间标记的返修说明，交给 Codex 或剪辑人员继续改。
5. 五项均通过或不适用、所有标记已处理，才能选择“审看通过”。这由审看人作判断，文件生成不会自动通过。

记录保存在工程 reviews/lib-*.json。保存不改视频和渲染任务状态；浏览器暂存本页草稿。多页面保存冲突会保留文字，需读取新版、核对草稿后再保存。

文件路径、大小与修改时间共同标识版本。文件变化后，原有通过结论失效，显示上版记录并重新审看；保存新版本时归档旧记录。浏览器逐帧跳转按实际平均帧率计算，解码定位为近似帧，不宣称精确逐帧解码；变帧率片段建议继续用专业剪辑器核对。

本次方法依据知识库收藏中的：
- [Codex 动效视频方法](https://x.com/guanmo_ai/status/2105146205915283737)：每镜一个主事件、动作分层、音乐节拍与逐帧审片。
- [代码视频拆解](https://x.com/xilo2991/status/2104912748794589515)：确定性时间轴、静帧与短样片先行、逐项复核文字和声音。
- [15 个交互概念](https://x.com/AdrianPunk115/status/2107766819713065272)：保留输入、解释错误、区分空状态和失败、异步操作反馈。

这些方法是实现依据，不表示工作台已验证文章所称的模型效果或制作成本。自动返修、精确解码、整片听觉质量评估尚未实现；当前交付是实际播放器、持久化审片和可复制返修交接。
