# Codex 与 Windows 版剪映

核对日期：2026-10-07。

v0.2.0 起提供“工作台作品 → 剪映草稿 → 打开剪映”的桥接。Codex 继续负责脚本、分镜、生成与检查；剪映用于时间线精修和最终导出。早期 v0.1.0 分享包没有这些入口，需要更新工作台和 skill。

## 在工作台中使用

先在工作台根目录安装独立的草稿桥接环境：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-JianyingBridge.ps1
```

该脚本使用工作台现有 Python，在 `apps/jianying-bridge/.venv` 安装固定版本的社区库，
依赖清单为 `scripts/requirements-jianying.txt`；它不安装剪映本体，也不下载模型。
如工作台尚未安装，先按 [快速上手](getting-started.md) 准备基础运行环境。

剪映组件的固定依赖要求 **64 位 Python 3.12–3.14**；基础工作台可以使用 3.11，但剪映组件不能沿用 3.11。
默认安装器安装的是 Python 3.12。若已有工作台使用 3.11，请另装 Python 3.12，并用
`scripts/Install-JianyingBridge.ps1 -PythonPath '实际的 Python 3.12/python.exe 路径'` 指定解释器。
脚本会在安装依赖前检查版本；如旧的 `apps/jianying-bridge/.venv` 已用 3.11 创建，先把该环境目录改名备份，再重新运行，不要删除作品或剪映草稿。

1. 从 [剪映官网](https://www.capcut.cn/) 安装 Windows 版剪映，并完成首次启动。工作台会检测已安装的程序和草稿位置。
2. 在工作台“我的作品”打开一个已完成的视频工程，找到“送到剪映精修”。没有视频的空草稿、纯音频或预览任务不能直接交接。
3. 默认选择“自动选择”，点击“生成剪映草稿”。结果显示独立草稿名称、位置、实际采用的模式与提示；这一步生成草稿，不是让剪映导出 MP4。
4. 点击“打开剪映”，再在剪映草稿列表中选择返回的草稿名。若列表未刷新，可返回首页或重新打开剪映；不要为了刷新强制结束正在编辑的项目。
5. 检查画面、音轨、字幕和结尾，在剪映里导出到单独文件。Codex 有可用的 Windows 桌面控制工具时可继续操作这些步骤；成功依据是实际窗口及导出的媒体，而不是应用进程存在。

| 模式 | 适合情况 | 编辑范围 |
| --- | --- | --- |
| 自动选择 | 不确定工程是否保留全部镜头素材 | 根据工程现有文件选择可用方式，结果说明实际采用模式 |
| 素材分轨 | 保留完整镜头、配音及字幕的工程 | 调整镜头、角色音轨和字幕；无独立画面素材的白板/讲解镜头重建为可编辑标题、要点卡片 |
| 成片交接 | 只有最终视频，或希望保留原始画面与混音 | 对整片进行切割、包装和二次配音；不会自动分离原始角色声线或图层 |

字幕已烧录到成片时，不应再叠加一份相同的可见字幕。工作台会说明回退模式与缺少的素材；不要把“能看到成片”误认为所有组成元素都已变成剪映原生轨道。

白板/讲解重建卡片不会迁移原手绘描边、排版动效或转场；要保留原成片外观可使用“成片交接”。已有图片或视频素材内部的文字与图形仍属于画面，不会自动转换为剪映文本。
草稿位置优先读取剪映的 `globalSetting.currentCustomDraftPath`，尊重用户在剪映中设置的位置。

## 让 Codex 交接

安装或更新本仓库的 `$ai-video-studio` skill 后，直接说：

> 把刚才这条视频送到剪映，尽量保留镜头、配音和字幕轨道，打开草稿检查后导出一个独立的精修版本。

Skill 使用本机 HTTP API；以下 `CLIENT` 是其 `scripts/studio_client.py` 的完整路径：

```powershell
python CLIENT jianying status
python CLIENT jianying status --project 工程ID
python CLIENT jianying export --project 工程ID --mode auto
python CLIENT jianying open --project 工程ID
```

CLI 的 `export` 表示“生成剪映草稿”。`open` 只启动检测到的剪映，并提供草稿信息；不会声称已经打开指定工程，也没有调用社区库的旧版自动导出控制器。详细字段见 [Skill API 文档](../skills/ai-video-studio/references/api.md#剪映草稿交接)。

## 三种接入方式

| 方式 | 用途 | 需要什么 |
| --- | --- | --- |
| 素材交接 | 由工作台生成图片、视频、配音、配乐和 SRT，再导入剪映精修 | 工作台与剪映；素材本身不依赖剪映内部草稿格式 |
| 草稿交接 | 用社区库把素材、轨道、字幕和时间安排写成剪映草稿 | 匹配版本的草稿库，以及在目标剪映版本中打开验证 |
| 桌面操作 | 由 Codex 观察剪映窗口，执行导入、编辑和导出等界面操作 | 当前会话可用的 Windows 桌面控制工具、已安装剪映，以及可交互的桌面 |

分享包里的 skill 是创作流程说明，不会自动给 Codex 增加操作系统权限或桌面控制能力。接手任务时应检查当前可用工具。浏览器控制工具不能操作原生 Windows 窗口，也不等于另一个 Windows Computer Use 工具不可用。

## 社区草稿库的实际边界

[pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft) 是社区维护的 Python 项目，不是剪映官方 API。核对时上游 README 为 0.3.0，列出的本地图片/视频/音频、文本与 SRT 草稿生成能力支持剪映 10.8；具体特效仍有差异，例如蒙版、轨道顺序和字体有单独限制。

该库的自动导出依赖旧版 Windows UI 控件。上游明确标注剪映 5.9、6.8 测试通过，剪映 7 及以上的自动导出通常不可用。**这限制的是该库的自动导出实现，不代表所有桌面自动化都失效。** 新版界面操作仍须根据实际窗口逐步验证。上游的版本说明见 [README 批量导出部分](https://github.com/GuanYixuan/pyJianYingDraft#%E6%89%B9%E9%87%8F%E5%AF%BC%E5%87%BA) 与 [发布记录](https://github.com/GuanYixuan/pyJianYingDraft/releases)。

新版本剪映草稿不一定是可直接读取的 JSON。加载既有模板与从零生成草稿是不同能力；不要把“新草稿可打开”当成“任意已有模板可无损改写”。本工作台不要求降级剪映，也不提供加密草稿的解密实现。

国际版 CapCut 有独立社区项目 [pyCapCut](https://github.com/GuanYixuan/pyCapCut)。它与国内版剪映应分别验证，不能假设草稿和导出行为完全一致。

## 官方入口与 API 说明

剪映官方下载与产品入口为 [剪映官网](https://www.capcut.cn/)，另有 [剪映开放平台](https://open.capcut.cn/)。本次没有核实到可供此工作台直接调用、公开完整文档化的 Windows 桌面时间线控制 API。因此这里不把社区库、第三方“剪映 API”服务或网页营销介绍称为官方桌面 API。

## 数据与验收

2026-10-07 已在 Windows 的剪映专业版 **11.5.0.14471** 完成一次实际小样验收：
从工作台生成三镜头、双角色配音的 10 轨草稿，在剪映首页找到并打开草稿，
观察原生时间线和字幕预览，再由 Codex 操作界面导出。剪映显示导出成功；
得到约 34.92 秒的 H.264、1920×1080、30 fps 视频，音频为 AAC、44.1 kHz、立体声。
全片解码 1047 帧无错误；抽看 3、14、30 秒画面，文字和字幕未见溢出。
音轨已确认非静音，尚未主观听辨，因此不把这次验证描述为音色或配音质量通过。
这验证了当前版本的草稿交接与实际桌面导出，不是桥接 API 已支持无人值守批量导出；
剪映更新或改用其他项目、字体与特效时仍需复验。

桥接根据工作台工程另建剪映草稿，保留原工作台工程和交付文件。不要移动或删除仍被剪映草稿引用的素材；复制到其他机器时先检查素材路径和实际打开结果。后续编辑已有剪映工程前保留副本。

导出响应的 `delivery_dir` 给出该工作台工程的 `jianying/exports` 目录。剪映最终 MP4 可导出到这里，保留与原工程的关联；草稿本身和所需素材仍位于剪映草稿目录。刷新交接状态后，已写完且容器可读取的 MP4 显示为“剪映导出（待审）”；正在写入或不完整的文件不会作为成品提供下载。待审表示还需看画面、听声音，不是剪映导出失败。

输出草稿、在剪映打开成功、导出成功和成片验收分别记录。一个版本上的小样通过不能保证所有特效、模板、字幕或未来版本都兼容。只有成功调用本地接口而没有实际打开草稿时，应明确报告“草稿已生成，剪映内尚未验收”。
