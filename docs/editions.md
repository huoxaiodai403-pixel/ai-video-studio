# 朋友版与完整版

从 v0.3.0 起，工作台按两种用途维护。朋友版围绕 Codex 创作和本机交付提供清楚的起点；完整版用于持续开发更多生成路线。两个版本都把计划、预览和成片放入统一作品库。

| | 朋友版 | 完整版 |
| --- | --- | --- |
| 仓库 | [公开 ai-video-studio](https://github.com/huoxaiodai403-pixel/ai-video-studio) | 私有 `ai-video-studio-dev`，由维护者授权访问 |
| 主要使用方式 | 在 Codex 中创作文稿、分镜和动画；代码动画也可选用已配置的网页编剧；工作台负责渲染与交付 | 网页直接创作与 Codex 创作并行，按需使用本地模型或在线服务 |
| 主要范围 | 代码动画、手绘白板、配音、作品库、剪映交接 | 朋友版能力，以及角色叙事、角色循环、三维预演、调查长片等研发路线 |
| 安装目标 | 先准备网页环境和 CPU 渲染器，不默认下载大模型 | 按制作任务另行准备模型、显卡环境和服务 |
| 发布方式 | 从公开仓库的 Releases 下载 Windows 包与 Skill 包 | 在私有仓库维护完整源码；不随朋友版公开发布 |

这里的“完整版”表示维护范围更广，不表示所有模型、动作或长片流程都已达到成片质量。公开仓库的历史发布保留各自版本说明；下载时以对应 Release 的文件和说明为准。朋友版 Windows 包名为 `ai-video-studio-friend-0.3.0-windows.zip`，独立 Skill 包名为 `ai-video-studio-friend-skill-0.3.0.zip`。完整版 Windows 包使用 `ai-video-studio-development-0.3.0-windows.zip`。

## 朋友版能做什么

- **Codex 创作**：由当前会话写口播、设计分镜、编写动画，使用配套 Skill 检查环境并把计划或素材提交给本机工作台。朋友使用自己的 Codex 账号与额度。
- **代码动画**：渲染自包含 HTML、Canvas 或 SVG 动画，保留可编辑源码。适合图形、文字、关系和步骤讲解；有声版本还需实际可用的配音。
- **手绘白板**：按分镜组织文字、图形和公开贴纸，先预览再生成有声视频。CPU 渲染器不要求先装图像或视频模型。
- **配音**：基础方案是 Windows 系统语音；也可选需要联网的 Edge 或自行配置的在线语音。可用声线取决于本机和服务，分享包不附带作者的录音或克隆音色。
- **作品库**：集中查看计划、样片和成品，预览、搜索、收藏、下载，并回到对应工程继续修改。生成完成仍需实际审看。
- **剪映交接**：把已完成的视频或保留的镜头、声音和字幕交接为剪映草稿，精修后回收导出的 MP4。可编辑程度取决于原工程保留了哪些素材。

朋友版的起步路径是：**Codex 创作 → 本机短样片 → 修改与审看 → 完整渲染 → 作品库或剪映**。不需要为了写稿和代码动画先安装本地编剧模型。

Codex 内置生图、文件操作及桌面控制是否可用，取决于朋友当前会话的实际工具。Skill 提供操作流程，不会增加账号权限或凭空提供这些工具。工作台网页不会自行调用当前 Codex 对话里的媒体工具。

## 完整版的能力边界

完整版保留网页自动编剧与更多模型流水线，便于本机试验和逐步完善：

| 路线 | 当前定位与限制 |
| --- | --- |
| 自动编剧与代码方案 | 可生成可编辑草稿；本机约 9B 编剧的理解、画面设计和代码质量仍不稳定，不能把自动方案视为已审阅的成片设计 |
| 角色叙事 | 默认可做有声配图叙事；真实动态另需视频模型，人物身份、肢体、动作连续性仍需逐镜审查 |
| 角色循环 | 关键姿势生成和组帧；姿势不同不代表动作自然，透明边缘和循环接缝需要检查 |
| Blender 预演 | 用几何白模验证空间和相机运动；复杂角色、骨骼动画与最终生成画面仍需相应资产和后续制作 |
| 知识与调查长片 | 管理来源、章节、分镜和素材；需要实际足量的文稿与画面，不保证一句话直接得到可靠的十分钟成片 |

这些路线的存在，不代表安装完成后即可使用全部引擎。模型文件、运行环境、接口权限、生成成功和画面质量是不同的检查项。具体操作见对应工作流文档。

## 两个版本共同的约定

1. **保留工程。** 更新前备份自己的配置和作品，不用他人的配置覆盖已有声音、模型和服务设置。
2. **按实际文件交付。** 任务排队、草稿保存、样片生成和完整视频导出分别显示；样片不会冒充成品，文件生成也不会自动通过审片。
3. **分享软件与私人内容分开。** 发行包不包含个人工程、参考照片、录音、模型权重、密钥或机器日志。需要分享作品时，由用户另行选择文件。
4. **剪映导出单独确认。** 草稿已生成、剪映已打开、MP4 已导出和成片已审看分别核对。没有可用桌面工具时，可在剪映中手动完成精修与导出。

安装与基础使用见 [快速上手](getting-started.md)，剪映的素材与版本限制见 [剪映接入说明](jianying-windows.md)。
