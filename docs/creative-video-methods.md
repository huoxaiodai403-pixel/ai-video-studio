# 视频文章的创作方法

当前自定义创作、ComfyUI、Codex / Blender 交接和角色库操作见 [制作方式与角色](production-paths.md)。

工作台的 Codex Skill 已将新收藏视频文章中的十个项目纳入创作选型。直接说明你想做的内容与风格，例如“用纸张拼贴讲清这个概念”“把这段口播做成手绘视频”“用国风画面表现这首诗”。Codex 会据此读相应方法、编写分镜并使用工作台已有工具，不需要记住十套命令。

网页「工作流」也同步展示这些方法。每项包含准备条件、步骤、实际交付边界、进入创作和已有样片入口；9 项可在生成工坊选择「用我的内容创作」，Simon 使用原生白板编辑器输入自己的内容。后续更新固定来源、生产目录和示例后，运行 `tools/.venv/Scripts/python.exe scripts/sync_creative_methods.py` 更新网页投影；`test_workflow_catalog.py` 校验目录覆盖、示例隔离和计划 API 兼容性，避免只增加资料却漏掉入口。

| 创作方法 | 适合的内容 |
| --- | --- |
| 花叔艺术动画 | 数据、机制、代码绘制与艺术表达；参数图表可直接使用 CPU 渲染 |
| Vox 拼贴 | 纸张、照片、图形分层的解释和产品故事 |
| 手绘蜡笔 | 中文口播的视觉隐喻，稳定纸面与线条 |
| 火柴人导演 | 以人物动作讲清认知变化与行动结果 |
| 纸艺祝福 | 个性化生日和温暖的定格短片 |
| 诗词国风 | 按诗句分景，画中局部自然运动与可编辑诗句 |
| 人生漫画 | 统一主角、连续口播和足量漫画分镜 |
| Simon 白板/资料片 | 步骤、关系、证据与知识讲解 |
| 人物故事与剧情导演 | 按个人经历、知识解释和剧情冲突选择制作方法 |
| 书评与图书推荐 | 核实书籍、组织口播、统一字幕区与镜头节奏 |

每部作品沿用你选定的画幅、角色、音色与后端；真实声音决定字幕和画面时间，先验证代表短段，再完成整片。结果统一进入作品库与审片，不增加另一套工作台。

花叔柱状图与折线图已适配现有离线渲染器，保留输入数据、动画时间点及源码。火柴人、手绘讲解与 Vox 拼贴的固定示例和手工代码制作使用连续配音、真实时间轴、逐帧动画、字幕与源码交付，支持中断后继续和改画面复用原声。已有画面代码配合系统声音可使用 CPU 制作；网页自动创作新内容仍需要所选编剧服务，图像与高级声音还需对应后端。二维代码/拼贴运动不等于模型生成的角色动态。

纸艺祝福、诗词画卷、人生漫画、第一人称故事、书评和花叔机制片也提供同一条连续配音与交付流程；Simon 使用已有原生白板渲染器。十种方法均有具体本地制作示例、实际技术和输入要求，见[制作目录](../skills/ai-video-studio/references/creative-production-catalog.json)。固定示例的背景音保留独立原文件和混音，竖屏字幕按完整词组排版。

自定义创作与固定示例是两种用途。网页主入口按新文稿制作：代码动画重新编写画面，图像叙事调用所选生图引擎；Codex 也可以制作 Blender 场景或外部镜头，再交回同一计划配音合成。固定示例中的二维纸艺、静图漫画和 Storytime 仅用于演示，不能代表这些方法只有一种制作技术。

这些入口不表示上游全部模型、长片模式和账号服务已接入，也不表示十种新内容已经完成视听验收。每次作品都需保存实际素材并逐镜检查。操作、角色版本、声音优先级与交接边界见 [制作方式与角色](production-paths.md)。

开发与可执行命令见[各方法执行参考](../skills/ai-video-studio/references/creative-recipes.md)。资料安装器为 `scripts/install_creative_skills.py`，只安装固定提交中的文档、许可证和图表代码；原文及模型、音色、示例人物不纳入工作台源码包。继续使用 [组合制作](video-skills.md) 与 [生成工坊](generation-workshop.md)。

网页主流程为：选择方法 → 用我的内容创作 → 核对分镜、角色与声音 → 生成样片 → 完整制作。已有 Blender / Codex 镜头则填写真实素材路径，点击「合成已交回镜头」。完成后在作品库回看、下载与返修。

「用示例新建计划」与「复刻固定示例」仍用于了解原场景。启用复刻只修改标题和旁白，会使用示例画面与系统声音；更换视觉内容要保持复刻关闭。源代码包不包含这些个人素材。
