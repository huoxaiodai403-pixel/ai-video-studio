# 自定义视频、角色与制作交接

先在「工作流」选择视频方法，点击「用我的内容创作」，填写自己的主题、完整文稿、受众与目标时长。生成工坊会把这些内容保存为可编辑计划。完整文稿要求保留原文时，请在需求中明确说明，生成分镜后核对是否遗漏、改写或添加事实。

## 选择制作方式

| 方式 | 操作 | 交付与边界 |
| --- | --- | --- |
| 网页自动制作 | 生成方案 → 修改分镜 → 生成样片 → 完整制作 | 根据当前内容生成画面；模型输出仍需审看 |
| ComfyUI | 在角色叙事中选「本地模型」，选择本次图像引擎 | 生成新图；勾选真实动态镜头后才调用视频模型，静图推拉属于剪辑运动 |
| Codex 接管 | 在分镜页复制创作交接指令，交给当前 Codex 对话 | 使用同一计划、角色、音色与审片记录；可调用已配置模型、编写动画或制作 Blender 场景 |
| Blender | 简单空间和运镜用「Blender 动画与镜头预演」；完整场景交给 Codex 制作并渲染 | 预演是几何白模；完整建模、材质、灯光与动画需要真实场景工程，保留 `.blend` 和渲染视频 |
| 已有镜头合成 | 为每镜填写实际图片 / 视频路径，再点「合成已交回镜头」 | 复制素材快照，按所选音色配音并对齐字幕，不重新生图或重新设计动画 |

十种方法共享已有生成器，方法数量不代表十个独立模型。代码动画方法会根据新内容编写新画面；拼贴、诗词、人物漫画和书评默认通过图像叙事生成；Simon 使用原生白板编辑器。固定示例只是可选复刻模式，不能把换标题、换旁白的旧画面当作自定义制作。

## 找回自己的作品

从方法卡片点击「查看已有作品」，会按该 Skill 筛选全部对应成片，不依赖示例名称。作品库的「创作方法」可切换方法；「全部工程」还包含草稿、运行和失败任务。改名不影响方法归属，清除筛选不会删除作品。

从方法目录进入另一种生成工坊方法时，工作台先保存和备份当前计划，再建立该方法的新内容表单；保存失败会保留当前编辑。点击具体作品的「继续编辑工程」则恢复原计划。跨窗口出现版本冲突时先重新载入保存版本，不要强行覆盖另一窗口的修改。

重复保存相同内容不会增加版本，也不会让正在生成的结果被误判为旧内容。实际修改仍会建立新版；旧任务继续按提交时的快照完成。白板修改后会提醒重新生成，已完成的视频仍然保留。

## 配音先试听

在「音色库」选择或设计音色，再在本片中选「本地模型」和相应声线。已准备 Qwen3-TTS 等本地引擎时，新创作优先采用已配置声线；已有计划的选择保持不变。Windows 系统配音是无需模型的基础选项，固定示例复刻仍明确使用系统声音，不代表正式配音品质。

音色覆盖顺序为：镜头独立音色 → 说话角色绑定音色 → 全片旁白。系统配音不能替换已选择的本地角色声音。先用当前文稿试读，检查咬字、停顿、情绪和人物匹配；参考音频可播放不代表本次合成已听审。

## 角色库与长片

「资源库 → 角色库」保存名称、所属作品、外貌、服装、连续性备注、参考图和音色。保存会建立新版本。没有参考图的角色只有文字设定，不能据此保证人物一致。

- 生成工坊：选择本片角色，在分镜中指定出场角色和说话者；提交时保存角色与声音快照。
- 小说转漫剧、通用制作：从角色库带入固定版本，在各镜头选择出场角色。参考图生成需选择本地 FLUX.2 klein；一个镜头最多四张参考图。
- 资料长片：带入角色和音色，外貌参考保存在工程中。画面继续使用该长片登记的图片、视频和证据素材；带入角色不会自动替换已有资料。

角色库更新不自动改写已提交任务。返修应明确选择新版角色或新镜头，并保留已经通过的声音与素材。小说较长时按章节制作，复用同一角色版本，再在剪辑工作台组合章节。

## 生成失败或画面不合适

- 任务失败：点击「继续未完成部分」，沿用这次冻结的文稿、音色和服务，继续已完成阶段之后的制作。已经渲染并通过文件校验的镜头会复用；模型回复和具体错误保留在任务工程中。
- 画面不合适：在分镜写下具体返修要求，例如人物服装、动作方向、构图或字幕遮挡。修改内容后制作新版；不要将“生成完成”改写成“审片通过”。
- 代码动画：工作台控制逐帧时钟，编剧负责每一帧的绘制。代码通过校验仍可能画错动作或关系，需要实际检查。可让 Codex 修改动画，渲染后通过下方镜头交接回到同一计划。
- 编剧空回复或截断：这不是成片。工作台保留回复及结束原因；本地小模型的写稿能力不代表能可靠编写动画代码。连续重试仍失败时，换用代码能力合适的编剧，或将当前计划交给 Codex。原文、角色、音色和已完成媒体继续保留。
- 配音与字幕：原稿词级对齐可恢复标点并按实际边界断句；模型把相邻字对齐到同一时刻时，合并到实际测得的相邻区间，不估算新的发音时间。代码动画、图像叙事和交回镜头按同一帧时钟合并声音，避免各镜 AAC 编码填充累积偏移。在线识别使用服务实际返回的转录；听感、人物匹配和情绪仍需试听。

## Codex 与 Blender 交回

1. 保存计划，复制包含计划 ID、版本、原稿、分镜及角色的交接指令。
2. 在同一项目中制作镜头。Blender 保留真实 `.blend`、动画脚本和渲染设置，并导出 MP4；不要将白模改名为完整动画。
3. 将每镜真实图片或视频的完整本机路径填入分镜的素材字段。保存使用当前版本号，不能覆盖另一个窗口的新修改。
4. 点击「合成已交回镜头」。合成保留完整画面，长镜头按配音裁尾，短镜头停留末帧；使用本片配音替换输入视频声音。需要保留原声、特殊节奏或复杂混音时，在剪辑工作台处理。
5. 播放实际成片，检查首镜、中间、结尾、字幕、人物与声音。生成成功、完整解码、浏览器布局检查和实际视听是不同验收项。

API 调用：先以 `id` 和 `revision` 保存 `/api/generation/plan`，随后向 `/api/generation/compose` 提交 `plan_id`、最新 `revision`、`preview:false`、`source:"supplied"`。镜头素材和哈希保存在任务目录；重试使用这份快照。
