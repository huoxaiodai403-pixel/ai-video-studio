先把环境准备好

在解压后的工作台目录运行 Install.cmd 安装轻量网页环境，再运行 Start.cmd 打开工作台。模型权重需按任务单独准备；网页打开不代表所有引擎已安装。

通过 模型库 查看组件状态。本地图像与动态镜头需要 ComfyUI；配音、字幕、配乐各自使用对应引擎。白板和资料长片还需要浏览器渲染器。

完整安装步骤见 快速上手，本地引擎说明见 本地模型准备。在线接口在 设置 填写，并分别确认提供方支持图像、视频、配音或识别。

让 Codex 编排第一条视频

安装包内附有 ai-video-studio Skill。在工作台目录运行以下命令，然后在 Codex 打开此目录并开始新对话：

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-CodexSkill.ps1

可以这样提出需求：

使用 $ai-video-studio，先检查环境。制作三个镜头的白板讲解，主题是“核对信息来源”，面向普通读者，使用冷静清晰的中文。由你编写口播和分镜，先检查画面预览，再制作有声视频。

Codex 可以直接创作分镜并提交工作台，不需要安装本地编剧模型。可选的 Ollama 辅助写稿和小说原文分段仍然保留；按实际需求使用。

第一次先做少量镜头，确认表达和效果后再扩成长片。目标分钟数是创作目标；实际时长由最终音轨和镜头决定。

音色和素材可以跨工程复用

在 音色库 保存不同题材的声音预设，并在流程中给主持人、来宾或其他角色分配音色。先用短句试听语速、咬字与停顿，再生成长段落。支持的 Qwen 固定声线无需私人参考录音；参考克隆使用你有权使用的清晰单人录音。

图库与视频素材 可以上传参考图、查看生成画面并带入动态镜头或长片。FLUX 参考编辑需要对应完整模型组件；参考图有助于延续外观，仍需逐镜检查。

音频库 集中管理配音、音乐和音效。把音乐导入长片工程后可选为背景音乐；短音效不要直接当作全片循环配乐。

长片中的素材 ID 属于当前工程。复用其他工程的素材时从资源库重新导入；关联来源也需使用当前工程的台账。

所有成果在“我的作品”管理

打开 我的作品，搜索标题、筛选类型和状态、添加标签或收藏。成片、预览和草稿分开标注；生成完成后的主文件与交付资料集中展示。

白板、长片与保存的小说草稿可以从详情恢复到对应编辑页面。修改前确认打开的是目标工程；保留旧成片，需要另一个版本时另存工程。

下载前检查关键画面、配音和字幕，尤其是开头、转场与结尾。MP4 编码成功只说明文件产出，不能证明事实核对、画面质量或听感已经通过。

需要精调单张图时，再进入 ComfyUI

已安装 ComfyUI 和对应 Qwen GGUF 组件后，可以 下载 Qwen 入门工作流，在 本机 ComfyUI 导入。分享包不会替每位使用者安装模型或写入 ComfyUI 工作流列表。

先理解这条路径：模型加载 → 提示词编码 → 采样 → VAE 解码 → 保存图片。每次只调整一个变量，便于判断变化原因。手动生成的图片位于你的 ComfyUI 输出目录；需要在工作台使用时可导入图库。

参数作用注意
宽度 / 高度生成画面的像素尺寸不同模型有不同尺寸要求，成片放大不会增加原始细节。
Seed固定随机起点，便于比较相同种子不保证跨镜头人物完全一致。
Steps / CFG采样迭代和提示词引导先使用当前引擎的建议值，不把其他模型参数直接搬过来。
Frames / FPS动态镜头帧数和播放速率生成时长约为帧数除以帧率。

遇到问题先检查这些

  • 引擎未就绪：查看模型库缺项和任务错误。运行 Start.cmd 只会启动已安装的相关服务，不会补齐模型。
  • 显存不足：等待正在运行的任务结束，再降低分辨率或使用适合本机的引擎，避免同时在多个应用执行推理。
  • 素材或来源覆盖不足：在长片工程中补齐对应缺口，不把待核验内容直接改成“已核验”。
  • 配音不自然：先回到短句试听，比较音色、语速和表达要求；不要整片反复生成来试错。
  • 在线接口失败：确认具体媒体能力、模型名称与返回格式；“兼容聊天接口”不保证支持视频或字幕时间戳。
