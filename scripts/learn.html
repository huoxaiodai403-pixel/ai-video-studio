安装与快速上手

先准备好工作台与 Skill

在解压目录双击 Install.cmd 安装依赖，再双击 Start.cmd。按快速上手安装配套 Skill，在 Codex 打开工作台目录并开始新对话。

代码动画与白板使用 CPU 渲染，不要求先安装大模型。有声视频还需要实际可用的配音。

给 Codex 一个清楚的目标

使用 $ai-video-studio，先检查环境。制作三镜头白板讲解，主题是“核对信息来源”，面向普通读者，声音平静清晰。由你写口播与分镜，先给我短样片，保留工程。

需要图形动效时，把“白板讲解”换成“代码动画”。说明受众、关键问题、画风和声音即可，再按实际样片逐步修改。当前会话的工具与额度由自己的账号决定。

代码动画

把文字、图形、关系和步骤做成可修改的动画。Codex 编写源码，工作台渲染。

也可使用自己已配置的网页编剧生成方案。已有源码的手动渲染不需要编剧服务。

打开代码动画

手绘白板

用旁白和逐步出现的文字、图形讲清方法、步骤与对比。每镜头围绕一个要点。

先检查图形预览，再制作有声视频。需要新插图时，可由具备相应工具的 Codex 准备后导入。

打开手绘白板

声音与素材可以复用

在配音页先试听语速、咬字与停顿，再保存适合题材的声音。Windows 系统语音可离线使用，Edge 需要联网；包里不附带私人录音或克隆声音。

配音试听音色库图库音频库

完成的内容统一存到作品库

草稿、样片和成片分别显示，可以搜索、下载或继续编辑。先检查开头、转场、结尾、声音和字幕，再扩大内容；文件已生成不会自动表示质量通过。

需要精修时，从已完成作品详情进入“送到剪映精修”。草稿已生成、剪映已打开、MP4 已导出要分别确认；只有最终视频时，不能自动恢复其中的文字和声音图层。
