# AI 视频工作台 · 朋友版

这是可选的 Codex 对话入口。用户也可以直接使用工作台网页，不要求他复制指令、手写 JSON 或来回搬文件。

## 开始

运行 `scripts/studio_client.py doctor` 检查本机服务，`generation` 查看实际支持路线，`list --status all` 查作品。服务通常在 `http://127.0.0.1:8189`；路径从仓库或 API runtime 获取，不假定盘符。

朋友版支持：代码动画、手绘白板、Windows/Edge/在线配音、已准备的本地声线、音色与作品管理、素材导入、剪映交接。高级模型下载与管理、调查长片、角色循环、Blender、独立生成式视频和音乐不在此版本；不要尝试调用这些入口或修改版别文件绕过。

## 创作

- 用户选择 Codex 创作时，直接写口播、分镜和原创动画。代码动画使用自包含 HTML/Canvas/SVG/DOM，定义 `window.renderFrame(t)`，所有画面按秒数确定；不能联网、使用定时器或外部库。先生成短样片检查文字、构图和动作。
- 先保存生成计划，再调用 `generation-render` 渲染已写好的动画；传真实 `audio_path` 可带声音，也能先做无声画面。不要求重新调用工作台编剧。
- 网页自动编剧和自动动画使用朋友自己配置的编剧服务；默认声线未指定时可使用 Windows CPU 语音。明确选择的本地音色需要对应引擎，不能声称解压即有克隆声音。
- 白板沿用 Simon 渲染器，先预览图形，再制作有声视频。支持 Windows、Edge 或已配置在线语音，查看具体请求示例。
- 用户已有素材优先复用；当前 Codex 会话实际有生图工具时可以使用它，然后导入工作台。不要把 Codex 订阅当成通用媒体 API。

详见 [API 与白板](references/api.md) 和 [代码动画](references/generation.md)。

## 验收与剪映

任务返回编号只表示已提交。查询到实际产物后检查关键画面、播放、音画与字幕；没有主观试听依据就明确写待试听。自动生成不自动批准分镜。

作品统一进「我的作品」。需要剪映时先 `jianying status`，已装则创建草稿。缺客户端且用户已经明确授权安装时可直接安装；否则说明缺项并询问是否安装官方客户端。草稿生成不等于剪映已打开或导出完成。

保留原项目、配音和版本。仅上传经允许清单构建的源码包，个人配置、密钥、作品、录音、参考图和模型不进入公开仓库。
